# Hospital Patient Care Operations Analytics using SQL

## 📌 Project Overview

This project focuses on analyzing hospital patient-care operations using **MySQL**. It explores patient information, doctor details, room resources, appointments, and treatments to understand operational patterns and generate useful business insights.

The project uses SQL queries to analyze appointment demand, patient behaviour, treatment performance, doctor workload, room utilization, and appointment-related challenges.

## 🎯 Project Objectives

- Analyze appointment demand across different cities and medical services.
- Understand patient behaviour and identify repeat patients.
- Compare appointment patterns across booking channels and priority levels.
- Evaluate treatment status, cost, duration, and waiting time.
- Analyze doctor workload and room utilization.
- Identify cancellation, no-show, and rescheduling patterns.

## 🗂️ Database Structure

The project contains five relational tables:

| Table | Description |
|---|---|
| `patients` | Patient information and preferences |
| `doctors` | Doctor details, specialties, and employment status |
| `rooms` | Room types, equipment, and availability |
| `appointments` | Appointment dates, services, priorities, and booking channels |
| `treatments` | Treatment status, attempts, duration, waiting time, and cost |

Primary keys and foreign keys are used to establish relationships between the tables.

## ▶️ How to Run the Project

1. Install MySQL Server and MySQL Workbench.
2. Open the `SQL Project.sql` file in MySQL Workbench.
3. Execute the database creation and table preparation statements.
4. Ensure the required source tables and data are available.
5. Execute the SQL queries section by section.
6. Review the results generated by each analysis.
7. Execute the Views and Stored Procedures to explore reusable analysis.
